# Cross-ancestry refractive-error retinal regulatory architecture

Code and frozen aggregate evidence for a secondary analysis of European and East Asian refractive-error GWAS and adult retinal chromatin annotations. This project tests association-effect heterogeneity, not causal-effect equivalence or clinical prediction.

## Main result

Analysis universe: 3,112,573 SNPs. Retinal OCR: 380,615; DAR: 1,232; eligible comparator: 379,279. Primary sample OR 1.119, conditional exact CI 0.867–1.423, Fisher P 0.367. Full-set mean heterogeneity-score difference 0.0351. The informative matched-permutation set has 1,069 DAR and 59,215 comparator SNPs, difference 0.0647, P 0.334. These are different sets. The verified block bootstrap gives CI 0.821–1.438 and does not establish equivalence.

## Contents and reproduction boundary

- scripts/: original analysis, harmonization, annotation, QC and source-acquisition workflows. Configuration files retain historical paths and must be configured for a new installation.
- results/: retained aggregate analysis outputs. results/iovs_final_qc/TABLE2_EXACT_CI.tsv and BLOCK_BOOTSTRAP_PRECISION.tsv supersede historical display intervals and diagnostic precision outputs.
- figures/: frozen final main figures. These are published output artifacts, not freshly generated by this archive.
- metadata/: source-resource records; obtain third-party inputs from their providers under their terms.
- reproduce_summary.py: portable offline verification of reported OR, exact interval, permutation P and bootstrap interval from included aggregate files.

Run `python reproduce_summary.py` after installing NumPy, pandas and SciPy. Full raw-to-analysis reconstruction additionally requires the upstream GWAS, retinal annotations, paired LD/reference resources and original software environments; it was not rerun for this release. No claim of fully self-contained raw-data reproduction is made.

Primary source publications: Cheng et al., https://doi.org/10.1038/s41588-026-02576-0; Li et al., https://doi.org/10.1038/s41588-025-02454-1; S-LDXR, https://doi.org/10.1038/s41467-021-21286-1. Earlier project archive: https://doi.org/10.5281/zenodo.22726972. This new project-attributed archive does not replace or erase the provenance of earlier public releases.

The historical diagnostic overlapping-block analysis is not valid confirmation of precise confidence bounds. Prefer the nonoverlapping-row-partition bootstrap, retaining its residual dependence limitations. Raw GWAS, individual records, LD panels, manuscript files and personal correspondence are intentionally excluded.
